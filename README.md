# Тишина

Приложение для спокойного чтения: мини-истории, письма и притчи в тёплых плоских иллюстрациях.

## Концепция
- Не йога и не медитации — тексты, которые читаешь и расслабляешься.
- Главная: карточки как открытки (природа, закаты, горы, озёра), каждая = один текст, кнопка «Читать».
- Контент: стартовый пак пишется вручную + классика из общественного достояния (народные притчи, дзен-истории).
- Всё локально в JSON — работает офлайн.

## Статус
🚧 Обсуждение концепции, контент в работе.
