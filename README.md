# Тишина — ридер

Ридер электронных книг: .EPUB, .FB2, .ZIP. Всё обрабатывается в браузере, на устройстве.

## Статус
✅ Шаг 1 — парсинг (parser.js; тесты: `cd test && node run.js` — 22 проверки)
✅ Шаг 2 — полка: IndexedDB, «Читаю сейчас», Библиотека, импорт, детали книги, удаление (тесты: `node run-shelf.js`, `node run-ui.js`)
✅ Шаг 3 — пагинация (reader.js; тесты: `node run-reader.js` — 12 проверок)
🔶 Шаг 4 — экран чтения: настройки (размер/Serif-Times-Sans/темы) ✅, justify+абзацный отступ ✅, сноски-попап ✅; фиксы пагинации: точная ширина колонки (не режутся буквы), текст на всю высоту ✅; осталось: шторка оглавления, закладки
